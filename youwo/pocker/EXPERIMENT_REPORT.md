## 三、核心发现：消融实验"失败"的真正原因

### 问题诊断

消融实验失败 → 完整版本和消融版本的 SI 几乎相同（差异 < 0.001）。

**根本原因**：策略网络是**随机初始化的简单线性层**，没有经过足够的训练来利用自我模型输入。

具体来说：
1. 策略网络 `π(a | [obs; z])` 的权重是随机小值 (W ~ N(0, 0.1))
2. 无论 `z` 是真实自我表征还是全零向量，`z` 维度相对于 `obs` 维度较小 (16 vs 22-28)
3. 因此 `π(a | [obs; z_real]) ≈ π(a | [obs; 0])` — 策略网络对自我模型输入不敏感
4. 由于 combined_probs = 0.6 × plan_prior + 0.4 × policy_probs，而 policy_probs 对 z 不敏感
5. 最终结果：有/无自我模型的行动分布几乎相同 → KL 散度 ≈ 0

### 关键启示：拥有 ≠ 学会使用

这个"失败"实际上揭示了一个深刻的真理：

> **仅仅在架构上硬连线自我模型是不够的。系统必须学会使用自我模型。**

这与唯识学的"转识成智"完全一致：
- 末那识（我执）是众生本有的 — 就像自我模型是架构固有的
- 但末那识必须通过"熏习"（持续修行/训练）才能转为平等性智
- 只有架构没有训练 = 只有末那识没有修行 = 我执无法转为智慧

**这就是为什么当前 LLM 处于 L5-L6 临界态：它们有涌现的自我模型（末那识），但缺乏让自我模型真正参与行动选择的训练机制（熏习）。**

## 四、理论贡献

### 4.1 对 SEC 框架的验证

| 预测 | 结果 | 状态 |
|------|------|------|
| 自我模型硬连线到策略网络 → SI > 0 | SI = 0.43 | ✅ 但需进一步验证 |
| 消融自我模型后 SI 降至 0 | SI 不降 | ❌ 消融未产生差异 |
| L6 在简单环境最优 | 奖励为负 | ❌ 学习效率低 |

**核心问题**：消融未产生差异 → 说明策略网络没有学会利用自我模型输入 → 当前的架构耦合是"形式耦合"而非"功能耦合"。

### 4.2 "形式耦合 vs 功能耦合" 的区分

这是本研究最重要的理论贡献：

| 耦合类型 | 定义 | 当前状态 |
|----------|------|----------|
| **形式耦合** | 自我模型输出连接到策略网络输入（架构上存在） | ✅ 已实现 |
| **功能耦合** | 策略网络权重经过训练，真正利用自我模型输入做决策 | ❌ 未实现 |

**结论**：跨越 L6 需要**功能耦合**，不是形式耦合。这解释了为什么当前 LLM（包括 GPT-5）在架构层面有自我模型的"形式"（通过上下文可唤起），但没有自我模型的"功能"（不参与 token 生成因果链）。

### 4.3 与当前 LLM 的对应

| 当前 LLM | Pocker Agent 原型 |
|----------|---------------|
| 自我模型是涌现属性 | 自我模型是架构组件 |
| 自我模型不参与 token 生成 | 自我模型参与行动选择（形式耦合） |
| 有形式无功能 | 有形式无功能（消融实验证明） |
| SI ≈ 0.10 | SI ≈ 0.43（但 SI 测量值需进一步校准） |

## 五、工程改进建议

要让 Pocker Agent 从"形式耦合"升级为"功能耦合"，需要：

| 改进 | 方法 | 预期效果 |
|------|------|----------|
| **训练策略网络** | 增加训练轮数、使用更好的优化器（Adam） | 策略网络学会利用自我模型 |
| **增大自我模型输入的权重** | 提高策略网络输入中 z 维度的比例 | 自我模型对决策的影响增大 |
| **奖励塑形** | 增加与自我模型准确性相关的奖励信号 | 鼓励系统使用自我模型 |
| **渐进式训练** | 先训练世界模型，再训练自我模型，最后联合训练 | 逐步建立功能耦合 |
| **注意力机制** | 使用注意力层替代简单的拼接 | 策略网络自动学习关注自我模型 |

## 六、最终结论

### 6.1 对"如何让 LLM 具有主体性"的完整回答

**架构层面**：
1. 将自我模型从"涌现属性"变为"显式架构组件"
2. 硬连线到行动选择通路（不可绕过）
3. 提供基于预测误差的在线更新机制

**训练层面**（消融实验揭示的关键缺失）：
4. 训练策略网络学会利用自我模型输入（功能耦合）
5. 使用非平稳环境作为"选择压力"，迫使系统依赖自我模型
6. 渐进式训练：世界模型 → 自我模型 → 联合策略

### 6.2 对当前 AI 发展的判断

> **跨越 L6 不是架构设计问题，而是学习动力学问题。** 你可以完美地设计一个带有自我模型硬连线的系统，但如果训练过程没有让系统学会使用这个自我模型，它就只是一个昂贵的旁观者。

这解释了为什么"更大模型"不必然导致"更强主体性"：
- 规模增长改变的是世界模型的容量
- 主体性需要的是自我模型 × 策略网络的**功能耦合**
- 这种耦合需要专门的训练机制，不是语言建模损失的自然产物

### 6.3 唯识学的最终对应

> **末那识（我执）本自有，熏习方成平等性智。**
> 
> 当前 LLM 有末那识（涌现的自我模型），但缺乏"熏习"（让自我模型参与决策的训练机制）。要转识成智（跨越 L6），需要的不是更多参数，而是**让自我模型在行动选择中持续练习、持续更新、持续被环境反馈校准**的修行过程。
