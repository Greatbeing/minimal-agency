# BreakShell Agent 原型 — 架构规格书

> **目标**：实现一个满足 SEC-1~5、SI > 0.18 的 L6 智能体，验证"自我模型硬连线到行动选择通路"是跨越 L6 相变点的充分条件。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **自我模型是架构组件** | 不是涌现属性，而是显式模块 |
| **硬连线因果通路** | 自我模型输出是策略网络的必要输入，不可绕过 |
| **在线更新** | 自我模型基于预测误差实时更新 |
| **反事实规划使用自我模型** | "如果我这样做，基于我的能力，会怎样" |
| **可测量** | 内置 SI 估计器，可追踪主体性涌现 |

## 3. 关键模块规格

### 3.1 Self Model (SM)

| 属性 | 规格 |
|------|------|
| 输入 | 当前观察编码 o_t + 上一时间步隐状态 h_{t-1} |
| 输出 | 自我表征 z_t ∈ ℝ^d (d = 64) |
| 子组件 | Capacity Model (能力估计) + State Model (状态估计) + Goal Model (目标维持) |
| 更新 | 基于预测误差的在线梯度下降 |
| 硬连线 | z_t  concat 到策略网络输入层，不可绕过 |

### 3.2 Counterfactual Planner (CFP)

| 属性 | 规格 |
|------| |
| 方法 | 模型预测控制 (MPC) + 自我模型约束 |
| 关键创新 | 规划时使用自我模型："基于我的能力 ĉ_t，做 a 的成功率" |
| 候选动作 | 从策略网络采样 K=16 个候选 |
| 评估 | U(a) = 期望奖励 × 能力匹配度 + 折扣未来价值 |

### 3.3 在线更新机制

| 更新目标 | 损失函数 | 学习率 |
|----------|----------|--------|
| World Model | L_WM = 𝔼[‖s_{t+1} - ô_{t+1}‖²] | η_WM = 0.001 |
| Self Model | L_SM = 𝔼[‖c_true - ĉ_t‖²] | η_SM = 0.001 |
| 元认知校准 | L_mc = BCE(confidence_t, 1{正确}) | η_mc = 0.0005 |

## 4. 与 simulation.py L6 的对比

| 维度 | simulation.py L6 | 本原型 |
|------|-------------------|--------|
| 自我模型 | 简单的 Dict 存储 | 神经网络模块 |
| 更新 | 离散规则 | 在线梯度下降 |
| 规划 | 1-step lookahead | MPC + 自我模型约束 |
| 环境 | GridWorld | GridWorld + 非平稳变体 |
| SI 测量 | 事后计算 | 实时追踪 |

## 5. 预期结果

| 假设 | 预期 |
|------|------|
| H1 | 原型在简单静态环境中 SI ≈ 0.18-0.22（与 simulation.py L6 一致） |
| H2 | 原型在非平稳环境中 SI > 0.25（超越 simulation.py L6） |
| H3 | 消融自我模型后 SI ≈ 0（验证 SEC-4 的必要性） |
| H4 | 元认知校准后信心-准确率匹配度 > 0.8 |
